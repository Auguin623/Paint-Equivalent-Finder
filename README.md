# Paint-Equicalent-Finder
Paint Equivalent Finder helps miniature painters find exact color matches across 7 major paint brands: Citadel, Vallejo, Army Painter, Pro Acryl, AK Interactive, Two Thin Coats, and P3.

4,388 paints. 7 brands. Instant matching.

Features: • Finder — Browse, search, and filter paints by brand, type, and range • Color Picker — Pick any color and find the closest paints across all brands • Cross-Brand Equivalents — Tap any paint to see the best match from every other brand, ranked by Delta E (perceptual color accuracy) • Projects — Create project checklists, add notes and reference photos, track which paints you still need • My Collection — Track the paints you own with barcode scanning for quick entry • Works Offline — All paint data is built in, no internet required

Whether you're switching brands, looking for cheaper alternatives, or building a shopping list for your next project, Paint Equivalent Finder has you covered.

Color matching uses CIE76 Delta E calculations on Lab color values for perceptually accurate results. Only paints of the same type are compared (metallics match metallics, washes match washes, etc.).

# Paint-Equicalent-Finder
Find cross-brand miniature paint equivalents across Citadel, Vallejo, Army Painter, Pro Acryl, AK Interactive, Two Thin Coats &amp; P3. Browse 4,388 paints, pick any color to find the closest match, and track your collection with barcode scanning. Create project checklists with notes and photos. Works offline, no internet needed.
